# Outpost Original 3D Model Pack

The OBJ models in this directory are original lightweight game meshes generated for Five Star Interactive's Outpost. Each uses triangle faces and the shared `outpost.mtl` material palette. Models are licensed under the repository's MIT License.

Models: oak tree, rock deposit, supply crate, adventurer torso/head/arm/leg, steel sword, kite shield and cloth cloak. Build-in animation is added in GDScript by moving rig nodes; these are not bone-skinned animated models.

They are low-poly original **mesh assets**, not generated spheres and boxes. Imported with Godot's OBJ importer.
