# Outpost Original Art Pack (v0.2)
Ten handcrafted original 64×64 SVG sprites: `wood`, `stone`, `hide`, `coins`, `gather`, `attack`, `craft`, `heart`, `spear`, `flag`.
These are authored specifically for Outpost and do not use Albion assets or third-party images. Godot 4.6 imports SVG as scalable UI textures.
World environment, character and boar are assembled from built-in Godot meshes to keep Android GPU cost low.
