# Material Symbols (outlined)

Selected 24 px SVG icons from Google's official [Material Design Icons / Material Symbols repository](https://github.com/google/material-design-icons), licensed under **Apache License 2.0** (see LICENSE). SVG paths are retained, with white fill added for dark Godot HUDs. Icons are bundled locally; no runtime network connection is needed.

Source pattern: `symbols/web/{name}/materialsymbolsoutlined/{name}_24px.svg` (Google master, retrieved November 2026).

Load icons as `load("res://assets/material_symbols/door_front.svg") as Texture2D` for `Button.icon` and `TextureRect.texture`.
