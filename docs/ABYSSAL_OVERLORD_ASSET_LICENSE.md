# Abyssal Overlord – commercial-use asset provenance

The GM-only **Abyssal Overlord** boss in Outpost uses an existing, animated
**Demon** from the **Quaternius Cube World Kit (August 2023)**.

- Source: https://quaternius.com/packs/cubeworldkit.html
- Source creator: Quaternius
- Licence published on creator's pack page: **CC0 1.0 Universal**
- Commercial game use: **permitted**
- Attribution: **not required**, but recorded voluntarily
- Included source asset: `res://assets/third_party/quaternius_cube_world/Enemies/glTF/Demon.gltf`
- Game model mapping: `res://scripts/creatures/cube_world_visual.gd` (`demon`)
- Boss script: `res://scripts/creatures/gm_abyssal_overlord.gd`

The linked Warcraft fan model was **never imported** into Outpost. This
replacement does not contain that model, its animations or its textures.
The boss name and gameplay are Outpost-specific.

The boss is **GM-only** and not part of natural terrain/dungeon spawning:
`.spawn overlord` / `.despawn overlord`.

Licensing evidence checked on the creator's page on 13 November 2026.
