# Changelog

## 0.4.0-dev — Interactive crafting and gathering overhaul
- Ten gatherable resources: wood, stone, fiber, berries, iron, coal, clay, herbs, mushrooms and reeds.
- Thirteen recipes across workbench, forge, loom and campfire.
- Visually staged ingredients, selectable recipes, timed hands-on station actions and a full completion reveal.
- Station models with animated components; themed resources and original icons.
- Iron blade, cloak, refined ingots, linen, bricks, tonic and stew.
- Crafted equipment updates gathering, movement, defence and damage.
- Production materials are only spent upon completion, never on cancellation or closing the app.
- Previous v0.2/v0.3 save format compatible; upgraded save version 4.
- Regression tests for resource types, stations, ingredient staging, time + manual work gates, cancellation, forging and combat.

## 0.3.0-dev — Inventory and crafting
- Real inventory window, data-driven recipes, contextual interaction and reduced notification spam.
- Heals, weapon strikes, shield mechanics, and first visual improvements.
